Meetup Runbooks

Six short checklists that take you from an empty calendar slot to a published recap. Your progress is saved in your browser, so you can close the tab and pick up where you left off. Start about three weeks before the event.

1 · Book a venue

Lock the room before anything else, the date depends on it. See the handbook’s venue criteria for what makes a good space.

2 · Line up a session host

A confirmed venue makes it easy to invite a host. Remember: first-timers welcome, offer to help them prepare.

No host this month?

Run a show & tell or a social. A dependable rhythm matters more than a packed agenda.

3 · Set up the event page

Your RSVP platform is the single source of truth. Create the event once all the details are firm.

4 · Promote the event

Post early, remind often. Use the communications guidance for channels and timing.

5 · Day-of run of show

Arrive early, set a warm tone, and keep to time so everyone catches transit home.

Safety first, always

You have the authority to pause an activity or ask someone to leave if behaviour makes others unsafe. See the Code of Conduct.

6 · Post-event recap

A tidy wrap-up keeps hosts happy and the community in the loop.

Checklist0/6 done
Better late than never

If the recap slips, publish it anyway, our community would rather read a late one than none at all.
